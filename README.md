# shil-ai

Personal site of [Eugene Shilnikov](https://shil.ai) — Group CPO at Fortis Group & Life Pay, Dubai. Public notes, code snippets, and case studies on AI tools and personal agents.

## Live site

→ [shil.ai](https://shil.ai) (deployed via Vercel)

## Stack

- [Astro 5](https://astro.build) (static site generator)
- [Astro Micro](https://github.com/trevortylerlee/astro-micro) theme by Trevor Tyler Lee
- TailwindCSS, MDX, Pagefind (search), RSS, sitemap
- Hosted on Vercel

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:4321

## Content

- `src/content/notes/` — public notes (synced from a `Public/` folder in private Obsidian vault)
- `src/pages/` — top-level pages (homepage, about)
