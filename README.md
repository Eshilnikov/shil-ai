# shil-ai

Personal site of [Eugene Shilnikov](https://shil.ai) — Group CPO at Fortis Group & Life Pay, Dubai. Public notes, code snippets, and case studies on AI tools and personal agents.

## Structure

```
shil-ai/
├── site/        # Astro source for shil.ai
├── posts/       # Public markdown notes (synced from Obsidian vault)
└── snippets/    # Public code: Telegram plugin patches, sync scripts, configs
```

## Live site

→ [shil.ai](https://shil.ai) (deployed via Vercel)

## How content gets here

- **`posts/`** — synced automatically from a `Public/` folder in my private Obsidian vault. The vault repo (`lifeos-content`) is private; only notes I explicitly mark as public propagate here.
- **`snippets/`** — manual additions when I have something worth sharing (e.g. patches to the Telegram Claude Code plugin, the Oura HRV sync script, the evening coach launchd config).
- **`site/`** — the Astro source for the homepage, blog, case studies, and "work with me" pages.
