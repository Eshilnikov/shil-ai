# site/

Astro source code for shil.ai.

## Local dev

```bash
cd site
npm install
npm run dev
```

Open http://localhost:4321

## Deploy

Auto-deploys to Vercel on every push to `main`. Production: [shil.ai](https://shil.ai).

## Stack

- Astro 5+
- Markdown content from `../posts/`
- TypeScript
- Tailwind CSS
- Deploy: Vercel

(Filled in once Astro is initialized.)
