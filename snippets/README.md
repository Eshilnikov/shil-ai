# snippets/

Public code excerpts from Eugene's personal AI stack.

What you'll find here over time:
- Patches to the official Telegram Claude Code plugin
- Sync scripts (Oura → SQLite, vault → GitHub mirror)
- Launchd plist configs for personal agents (evening coach, daily syncs)
- Shell scripts for common workflows
- Config snippets (`.claude/CLAUDE.md`, hooks, settings.json examples)

Each snippet has its own README explaining: what it does, prerequisites, how to adapt for your setup, and which posts on [shil.ai](https://shil.ai) cover it in depth.

These are real artifacts from a working personal system, not idealized examples. Sometimes ugly. Always honest.
